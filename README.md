# parcial_geocomp2026
Parcial Geocomputacion 2026 - Tecnicatura en Gxe e IT
Profs. Hernan Casaubon y Pablo Serratti

En el directorio "scripts"" se encuentra el archivo "Parcial1bis.R"", siendo este el script del parcial propiamente dichio
El documento lab.mdq es un quarto experimental, un borrador en el que se fueron probando funciones, quiza util de consulta
para ver los entretelones del proceso de aprendizaje, por eso se conserva.

En el directorio "data" tenemos tres  categorias "outputs-maps", "raw" y "processesed". En "raw" se encuentran los datos base
mientras que en "processed" los archivos resultantes de los sucesivos procesamientos que implica el parcial, en caso de que 
desee consultarse; a su vez aquí contamos con un subdirectorio net, donde se encuentran guardados los archivos vinculados a 
redes para cargar en cualquier momento. Finalmente "outputs-maps" es para los mapas y graficos.
